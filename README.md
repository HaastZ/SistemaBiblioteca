# 📚 Sistema de Livraria - Desafio Java

Bem-vindo ao repositório do Sistema de Livraria, um projeto desenvolvido como parte do desafio da formação em Java da Rocketseat. O objetivo deste sistema é gerenciar o empréstimo de livros em uma biblioteca, permitindo a listagem de livros disponíveis e a realização de empréstimos.

# 🚀 Tecnologias Utilizadas

- Java: Linguagem principal do projeto

- Paradigma Orientado a Objetos (POO)

- Coleções Java (ArrayList) para armazenar dados

- Scanner para interação via console

# 📌 Funcionalidades Implementadas

- Listagem de livros disponíveis para empréstimo

- Empréstimo de livros com atualização de disponibilidade

- Cadastro de novos livros

- Um menu interativo para facilitar a navegação

- Consultar histórico de empréstimos de um Usuario/Cliente

- Buscar um livro na biblioteca por titulo

# 🔄 Empréstimo de Livros

- Usuário escolhe um livro pelo Nome

- Insere seu nome para registrar o empréstimo

- O sistema atualiza o status do livro para "indisponível (false)"

# ⚡ Como Executar o Projeto

- Clone o repositório: git clone https://github.com/HaastZ/SistemaBiblioteca.git

- Abra o projeto em sua IDE (IntelliJ IDEA, Eclipse, etc.).

- Compile e execute a classe principal.

- Siga as instruções exibidas no console para interagir com o sistema.
